# Réseau Alliance Genève — site web

Refonte 2026 du site [reseaualliance.ch](https://reseaualliance.ch/). Site statique, sans build : ouvrir `index.html` ou déployer le dossier tel quel (Vercel, Netlify, IONOS…).

## Structure
- `index.html` — Notre agence (Qui sommes-nous ?)
- `groupe-reseaualliance.html` — Groupe Réseau Alliance
- `trouver-un-emploi.html` — Trouver un emploi
- `contact.html` — Contact
- `mentions-legales.html`, `conditions-generales.html`, `protection-des-donnees.html`, `credits-photos.html`
- `assets/style.css`, `assets/main.js` (menu mobile), `assets/img/`
- `video/hero-groupe.mp4` — **à déposer** : vidéo de fond de la page Groupe (l'ancien site utilisait `pexels-tima-miroshnichenko-5438941-1080p.mp4`). Tant que le fichier est absent, la photo de Genève sert de fond.
- `CONTENU-ORIGINAL.md` — inventaire mot pour mot du contenu de l'ancien site, référence pour toute modification.

## Design
- Couleurs issues du logo : rouge `#E42330`, bleu `#1F4E9A`, navy `#0F2D5C`.
